# 调试协议（本地命令端口）

调试模式打开后，App 在 `127.0.0.1:8765` 上监听命令端口。用途：用命令驱动 App 做断言，
不再靠「截图 + 坐标点击」；也可以一条命令改掉「检查更新用的源」，方便测试题库更新。

## 打开调试模式

关于页 → 版本号连点 7 次 → 输入调试密码 → 设置页出现「打开调试面板」。

## 连接

```bash
adb forward tcp:8765 tcp:8765
python tools/debugctl.py -c "help"
# 或者交互模式
python tools/debugctl.py
```

`tools/debugctl.py` 依赖 Python 3 标准库，会自动执行 `adb forward`。

## 协议

一行一条命令；服务端一行一条 JSON 响应。

```
-> state
<- {"ok":true,"port":8765,"currentPaperId":"import-20261108-114627",
    "papers":[...],"currentSourceId":"u_1794144390","sources":[...]}
```

出错时：`{"ok":false,"error":"中文原因"}`。

## 命令

| 命令 | 说明 |
|---|---|
| `help` | 列出全部命令 |
| `ping` | 连通性检查 |
| `state` | 当前试卷 / 进度 / 源 / 端口状态 |
| `paper list` | 本地试卷列表 |
| `source list` | 题库源列表（内置源账号会打码） |
| `source add <name> <baseUrl> <user> <pass> [path]` | 新建自建源并设为当前 |
| `source set <id>` | 切换当前源 |
| `source delete <id>` | 删除源 |
| `source builtin` | 恢复并设为默认源（仅特供版） |
| `update` | 用当前源检查题库更新，返回可更新列表 |
| `update source <baseUrl> [user] [pass] [path]` | 改「检查更新用的源」：同地址的自建源就改它，没有就新建并设为当前 |
| `quit` / `close` | 关闭连接 |

参数里带空格时用双引号包起来。

## 典型用法：测题库更新

```bash
# 1. 指向一个测试源（比如本机 mock WebDAV）
python tools/debugctl.py -c "update source http://10.0.2.2:8099/dav/ testuser testpass shuaati/"
# 2. 上传/制造一份更高版本的试卷后，检查更新
python tools/debugctl.py -c "update"
```
