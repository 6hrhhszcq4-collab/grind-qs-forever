# 题库 JSON 格式

一套题库存成一个 JSON 文件（本地导入的文件、或源上 `<paperId>.json` 的文件都是这个格式）。

## 顶层结构

```json
{
  "meta": {
    "title": "题库名",
    "total": 131,
    "counts": { "single": 95, "judge": 34, "multi": 2 },
    "source": "来源说明（可省略）"
  },
  "questions": [ ... ]
}
```

`meta` 只用于显示，`questions` 是必填数组。

## 单题结构

```json
{
  "id": "C001",
  "paper": 1,
  "type": "single",
  "no": 1,
  "stem": "安全帽的主要作用是（    ）",
  "options": [
    { "key": "A", "text": "防止高空坠物砸伤头部" },
    { "key": "B", "text": "装饰美观" },
    { "key": "C", "text": "遮阳" },
    { "key": "D", "text": "防雨" }
  ],
  "image": null,
  "answer": "A",
  "explain": "安全帽是防止头部受冲击的个体防护用品。"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 全局唯一；同步进度靠它对齐 |
| `paper` | 否 | 第几套卷（默认 1）；进度迁移用 (paper,type,no) |
| `type` | 是 | `single` 单选 / `judge` 判断 / `multi` 多选 |
| `no` | 是 | 卷内题号 |
| `stem` | 是 | 题干 |
| `options` | 是 | `[{key,text}]`；判断题用 `T`/`F` 两个选项（text 写「对」「错」） |
| `image` | 否 | 图片路径（相对这套试卷的 `images/` 目录）或 null |
| `answer` | 是 | 单选 `"A"`、判断 `"T"`/`"F"`、多选 `"ABC"` |
| `explain` | 否 | 解析 |

## 源上的索引（papers.json）

```json
{
  "papers": [
    {
      "id": "hanjie-202610",
      "name": "教程配套题库",
      "file": "hanjie-202610.json",
      "total": 131,
      "version": 5,
      "updatedAt": "2026-11-08 11:45"
    }
  ]
}
```

App 上传试卷时：先按 id 匹配云端条目，找不到再按名称匹配（同名视为同一套卷）→ 原地更新、`version` 自增；其余条目原样保留。

## 版本文件（version.json，可选）

```json
{
  "paperId": "hanjie-202610",
  "version": 9,
  "updatedAt": "2026-11-08",
  "note": "教程配套题库"
}
```

更新检查优先读它（单卷源用）；读不到（404）回退到 `papers.json` 里各条的 `version`。
